Three.js 入門 ― ブラウザで3Dを動かそう

2026-10-05

Three.js とは

Three.js は、ブラウザの中で3Dを動かすための JavaScript ライブラリです。HTML と CSS で「ページの見た目」を作れるようになったら、次は Three.js で「ページの中に立体の世界」を作れます。

  • 何ができる？ 回る立体、3Dキャラクター、宇宙や街並み、マウスに反応する背景など
  • 必要なもの ブラウザとテキストエディタだけ。インストールするソフトは不要
  • 料金 無料（MITライセンスのオープンソース）
  • 作者 Ricardo Cabello（通称 mrdoob）。2010年に公開され、今も活発に更新中

HTML/CSS とのつながり

学んだことThree.js での使われ方
HTML<canvas> や <script> を置く「土台」になる
CSS3D画面を全画面にする、上に文字やボタンを重ねる
JavaScript3Dの物体を作る・動かす（ここが新しく学ぶ部分）

つまり、今まで学んだことはそのまま使えます。Three.js は「HTML の上に3Dの窓を開ける道具」と考えると分かりやすいです。

なぜ自分で WebGL を書かないの？

ブラウザで3Dを描く本来の仕組みは WebGL（最近は後継の WebGPU）です。ただし直接書くと、三角形1枚を出すだけで100行近いコードが必要です。Three.js はこれを包んでくれるので、数十行で回る立体が作れます。

なぜ今流行っているのか

Webサイトは「読むもの」から「体験するもの」へ変わっていて、その中心にいるのが Three.js です。ブラウザで3Dを扱うライブラリとしては世界で最も使われており、GitHub のスター数は10万を超えています。

流行っている理由

  1. スマホでも動く ― 最近のスマホは3Dを軽く動かせるので、アプリを入れずに URL を開くだけで3D体験ができる
  2. ひと目で印象に残る ― 広告、新商品のページ、ポートフォリオで「他と違う」を出せる
  3. 商品を回して見られる ― 靴・車・家具を 360度回したり色を変えたりできる（ECサイトで人気）
  4. ブラウザゲーム ― インストール不要の3Dゲームが増えている
  5. ツールが充実 ― React で使える React Three Fiber、無料の3Dモデル作成ソフト Blender などと組み合わせやすい
  6. AIと相性がいい ― AIに「Three.js で回る地球を作って」と頼むと動くコードが出てくる。サンプルが多いのでAIも得意

どんなところで使われている？

分野例

公式サイトの examples を開いてみよう。「これがブラウザで動いてるの？」という作品がたくさんあります。

3Dの基本：「映画の撮影」で考える

Three.js のコードは、どれも「舞台を作る → 役者を置く → カメラで撮る」の順番で書きます。この5つの登場人物さえ覚えれば、どのサンプルも読めるようになります。

用語映画でいうとコード例
Scene（シーン）舞台・セットnew THREE.Scene()
Mesh（メッシュ）役者・小道具new THREE.Mesh(形, 質感)
Light（ライト）照明new THREE.DirectionalLight()
Camera（カメラ）撮影カメラnew THREE.PerspectiveCamera()
Renderer（レンダラー）カメラマン＋スクリーンnew THREE.WebGLRenderer()

座標は x（左右）・y（上下）・z（手前と奥） の3つ。CSS の top / left に奥行き z が加わったもの、と考えると分かりやすいです。

やってみよう：HTML 1枚で回る立方体

下のコードを index.html として保存し、VS Code の拡張機能「Live Server」で開くと、青い立方体が回ります。インストールは不要で、Three.js はネット（CDN）から読み込みます。

完成形を見る ▶

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめての Three.js</title>
  <style>
    body { margin: 0; }          /* 余白を消して全画面に */
    canvas { display: block; }
  </style>
  <!-- Three.js をどこから読むかを指定 -->
  <script type="importmap">
    { "imports": { "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js" } }
  </script>
</head>
<body>
  <script type="module">
    import * as THREE from "three";

    // ① 舞台
    const scene = new THREE.Scene();

    // ② カメラ（視野角75度・画面の縦横比・見える範囲）
    const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
    camera.position.z = 3;  // 少し手前に下がる

    // ③ レンダラー（canvas を作って body に追加）
    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setSize(innerWidth, innerHeight);
    document.body.appendChild(renderer.domElement);

    // ④ 役者：形（箱）＋質感（青）
    const geometry = new THREE.BoxGeometry(1, 1, 1);
    const material = new THREE.MeshStandardMaterial({ color: 0x1d4ed8 });
    const cube = new THREE.Mesh(geometry, material);
    scene.add(cube);

    // ⑤ 照明
    const light = new THREE.DirectionalLight(0xffffff, 3);
    light.position.set(2, 3, 4);
    scene.add(light);

    // ⑥ 毎フレーム少しずつ回して撮り直す
    function animate() {
      cube.rotation.x += 0.01;
      cube.rotation.y += 0.01;
      renderer.render(scene, camera);
    }
    renderer.setAnimationLoop(animate);
  </script>
</body>
</html>

コードの読み方

  1. <style> は普通の CSS。余白を消して canvas を画面いっぱいにしている
  2. importmap で「three と書いたらこの URL から読む」と決めている
  3. ①〜⑤は上の図の登場人物を、そのまま順番に作っているだけ
  4. ⑥ setAnimationLoop が毎秒約60回 animate を呼ぶ。少し回す → 撮る、のくり返しがアニメーションになる

つまずきやすい点

  • ファイルをダブルクリックで開くと動かないことがある → Live Server などのローカルサーバーで開く
  • 真っ黒な画面 → ライトを入れ忘れていないか、カメラが物体の中に埋まっていないか（camera.position.z）
  • 何も出ない → ブラウザで F12 を押して Console の赤いエラーを読む

演習課題

易しい順に並んでいます。できたところまで、隣の人と見せ合おう。

  1. 色を変える ― 0x1d4ed8 を別の色に。CSS の #1d4ed8 と同じ考え方
  2. 形を変える ― BoxGeometry を SphereGeometry(0.8, 32, 16) や TorusGeometry(0.6, 0.25, 16, 64) に
  3. 回転の速さ・向きを変える ― 0.01 を変える、片方の軸だけ回す
  4. 背景色を付ける ― scene.background = new THREE.Color(0xf0f4ff);
  5. 立方体をもう1個置く ― position.x で左右に並べる
  6. 上に文字を重ねる（CSS の復習） ― <h1> を position: absolute で canvas の上に置き、「3D背景のトップページ」に仕上げる

次のステップ

  • マウスで回せるようにする ― OrbitControls（ドラッグで視点を回せる部品）
